# Ace Retail Consultancy — website preview

Three-page static website for Ace Retail Consultancy Zambia.

- Home: `index.html`
- Services: `services.html`
- Work and contact: `work-contact.html`

The site is ready for GitHub Pages from the `main` branch at the repository root. It has no build dependencies.

The contact form opens an email draft addressed to Ace. A production form service can replace that behavior later. The hero photograph is concept imagery and should be replaced with approved Ace photography before the site is presented as final. The SVG logo is a recreation from the supplied raster artwork.
